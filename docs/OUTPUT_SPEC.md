# doc2md 出力仕様

doc2md の出力は 2 つあります。

1. **変換結果**: `<出力先>/<元ファイル名>.md` と `<出力先>/<元ファイル名>.assets/`
2. **変換レポート**: 標準出力（または `-o`）。形式は全ツール共通の [レポート出力形式 仕様書](https://github.com/shoyo-maya-bot/devtools-common/blob/main/docs/REPORT_FORMAT.md)（schema_version 1.x）

## 1. 変換結果（Markdown）

### ファイル

| パス | 内容 |
|---|---|
| `<stem>.md` | GitHub Flavored Markdown。UTF-8（BOM なし）、改行 LF、末尾に改行 1 つ |
| `<stem>.assets/<stem>-NN.<ext>` | 抽出した画像（出現順の連番 01, 02 …。同じ画像は 1 回だけ） |
| `<stem>.assets/<元ファイル名>.drawio` / `.svg` | draw.io のソースと書き出し（ペアで保管） |

- **途中で失敗しても壊さない**: 同じフォルダの一時ファイル（`.<stem>.md.*.tmp`）に書いてから置き換えます。
  変換が途中で失敗したときは、前回の `.md` がそのまま残り、途中までの `.md` や一時ファイルは残りません。
- **決定的**: 同じ入力・同じオプションなら、バイト単位で同じ出力になります（時刻・乱数を含めない）。
- 再実行すると `<stem>.assets/` は作り直されます（古い画像は残りません）。
- 1 回の実行で出力名が重なる入力があっても、前の出力を上書きしません。重なったものだけ名前を変えます（標準エラーと `convert.renamed` で通知）。
  - 拡張子だけ違う（`spec.docx` と `spec.xlsx`）: `spec.docx.md` と `spec.xlsx.md`（抽出図は `spec.docx.assets/` 等）
  - 別フォルダの同じ名前（`a/spec.docx` と `b/spec.docx`）: フォルダ構成を残して `a/spec.md` と `b/spec.md`
  - それでも重なる（大文字小文字だけ違う 等）: 入力のパス順に `-2`, `-3` … を付ける
  - 重ならない入力の名前は今までどおりです。比較は大文字小文字を区別しません（Windows・macOS に合わせる）。
- 前回の実行の出力は、同じ名前なら上書きします（再変換）。`--front-matter` 付きの出力で `source` が別の元ファイルなら、
  `convert.overwrite_other_source`（warning）を出し、その `id` は引き継ぎません。

### 構造の約束

| 要素 | 出力 | 備考 |
|---|---|---|
| 文書 | `# <元ファイル名>`（PDF / Excel / PowerPoint / draw.io） | Word は文書内のタイトル・見出しをそのまま使う |
| 見出し | `#`〜`######` | 1 段ずつしか深くならないよう詰める（H1 の次に H3 は来ない） |
| 段落 | 1 段落 = 1 ブロック。段落内の改行は行末 `\`（ハード改行） | 連続する空白は 1 つに |
| 箇条書き | `-` / `1.`、字下げ 2 スペースで入れ子 | レベルは直前 +1 まで |
| 表 | GFM の表。**1 行目は必ず見出し行** | セル内改行は `<br>`、`\|` はエスケープ。全列が空の列は削除 |
| 画像 | `![<名前>](<stem>.assets/<stem>-NN.png)` | |
| 本文外の文字 | `> **テキストボックス**: …` / `> **SmartArt**: …` | |
| 脚注・コメント | 本文に `[^1]` / `[^e1]`（文末脚注）/ `[^c1]`（コメント）、定義は文書末尾 | コメントは `コメント（作成者）: 内容（対象:「…」）` |
| ヘッダー・フッター（Word） | 末尾に `## ヘッダー・フッター` と箇条書き | 重複は除く。`--no-header-footer` で出さない |
| ページ（PDF） | 各ページの先頭に `<!-- page N -->` | 出典を追うための HTML コメント（表示されない） |

### エスケープ（元の文字を Markdown の記法として解釈させない）

元の文書の文字（Excel のセル値、段落、見出し）が Markdown の記法や HTML として解釈されて、
見出しや箇条書きに化けたり、描画で消えたりしないようにエスケープします。

| 元の文字 | 出力 | エスケープしないと |
|---|---|---|
| 行頭の `# ` `## ` … | `\# 大見出し` | 見出しになる |
| 行頭の `- ` `+ ` `* ` | `\- 項目` | 箇条書きになる |
| 行頭の `1. ` `2) ` | `1\. 手順` | 番号付きの箇条書きになる |
| 行頭の `>` | `\> 引用` | 引用になる |
| `---` `===` `***` だけの行 | `\---` | 区切り線、または前の行が見出しになる |
| 行頭の ```` ``` ```` `~~~` | `` \``` `` | コードブロックになる |
| 行頭の `[1]: …` | `\[1]: …` | リンク定義として行ごと消える |
| `<!-- … -->` `<b>` などの HTML | `\<!-- … -->` | 消える・タグとして解釈される |
| `&lt;` などの文字参照 | `\&lt;` | `<` に化ける |
| `\` | `\\` | 次の文字のエスケープになる |
| `\|` | `\\|` | 表の区切りになる |

- 段落の 2 行目以降（段落内の改行の後）も行ごとにエスケープします。行頭の空白は取り除きます（4 つ以上でコードブロックになるため）。
- 表のセルは `\` `|` `<` をエスケープし、改行は `<br>` にします。
- 脚注・文末脚注・コメントの本文（`[^1]: …`）も、本文と同じく HTML（`<`・`<!--`）と文字参照（`&lt;`）をエスケープします。
- Word の段落・見出しは、変換が意図して付けた記法（`**太字**`、`[リンク](URL)`、`[^1]`、変更履歴の `<ins>` `~~`）を残し、
  行頭の記法と HTML だけをエスケープします。
- 変換ロス検知では `\#` などのエスケープは元の 1 文字として数えます。

### 形式ごとの約束

**Excel**

- シートごとに `## シート名`（非表示シートは `## シート名（非表示）`）。
- 1 シートに表が複数あるときは、表ごとに `### 表N（A4:G10）`（範囲は見出し行から最終行）。1 つなら見出しなし。
- 表の上のタイトル行・作成者行、表の下の注記（※ 等で始まる 1 セルの行）は段落として表の外に出す。
  注記として表から外した行があれば `convert.warning` でセル位置を知らせる（表のデータを取りこぼしていないか確かめるため）。
- 見出し行は「7 割以上が数値でない行」に加え、数値を含む見出しも次のどれかなら見出しとみなす:
  年度が増える（減る）一方に並ぶ（`項目 / 2024 / 2025 / 2026`）、その行だけ太字、数値が文字列として入力され下の行は数値。
- 1 列だけの範囲は、先頭行が短い文字列で本文が 3 行以上あり、先頭行だけ太字か本文がすべて数値なら表にする
  （タイトル・作成者・注記の数行と取り違えないため。※ 等で始まる行があれば表にしない）。
- 表らしい範囲（2 つ以上の値が並ぶ行が 2 行以上）なのに見出し行が見つからないときは、`値 / 値` の段落で出し、
  `loss.table_as_paragraph`（warning）で範囲を知らせる。`--header-row` で見出し行を指定すれば表になる。
- 2 段の見出しは `親/子`（例: `金額/税抜`）。見出しの結合は全列に同じ名前を入れる。
- 本文の **縦結合** は上の値を繰り返す（検証しやすくするため）。横結合は先頭の列だけに値。
- 値は **セルの表示形式どおり** に出す（Excel の画面に見えている文字と同じにする）。数式は保存されている計算結果、
  真偽値は `TRUE` / `FALSE`。

  | 表示形式の例 | 値 | 出力 |
  |---|---|---|
  | `000` / `0000` / `000-0000` | 1 / 42 / 1234567 | `001` / `0042` / `123-4567` |
  | `0.00` / `#,##0` / `#,##0.00` | 1.5 / 1234567 / 1234.5 | `1.50` / `1,234,567` / `1,234.50` |
  | `0%` / `0.0%` | 0.125 | `13%` / `12.5%` |
  | `"¥"#,##0` / `#,##0"円"` / `#,##0_);(#,##0)` | 1500 / 1500 / -1500 | `¥1,500` / `1,500円` / `(1,500)` |
  | `@`（文字列） | `007` | `007` |
  | `yyyy/mm/dd` / `yyyy-mm-dd` / `m/d` | 2026-04-05 | `2026/04/05` / `2026-04-05` / `4/5` |
  | `yyyy"年"m"月"d"日"` / `m月d日(aaa)` | 2026-04-05 | `2026年4月5日` / `4月5日(日)` |
  | `h:mm` / `hh:mm:ss` | 9:07:03 | `9:07` / `09:07:03` |
  | `[h]:mm` / `[h]:mm:ss` / `[mm]:ss`（経過時間） | 1.5（36 時間） | `36:00` / `36:00:00` / `2160:00` |
  | `ggge"年"m"月"d"日"`（和暦） / `ge.m.d` | 2026-04-05 | `令和8年4月5日` / `R8.4.5` |

  - 端数は四捨五入（Excel と同じく 0.5 は切り上げ）。正・負・ゼロで書式を分けた形式（`;` 区切り）にも従う。
    文字色（`[Red]` 等）・幅合わせ（`_)`）は出力しない。
  - 表示形式が「標準」のセルと、地域設定に従う既定の日付（組み込みの短い日付 `mm-dd-yy` 等）は従来どおり:
    日付 `2026-04-01`、日時 `2026-04-01 09:30`、整数の小数は `1000`（`1000.0` にしない）。
  - **再現できない表示形式**（指数 `0.00E+00`、分数 `# ?/?`、条件付き `[>=100]`、
    システムの長い日付 `[$-F800]` 等）は「標準」と同じ値を出し、`loss.number_format`（warning）で表示形式とセルを知らせる。
- 20 万セル（`--max-cells`）を超えるブックは省メモリ読み込み: 1 シート = 1 表、結合・複数表・注記の判定なし
  （表示形式は反映する）。`convert.large_workbook`（warning）で知らせる。`--header-row`（指定の行を見出しにし、
  その上の行は段落）と `--skip-hidden`（シートの XML から読んだ非表示の行・列を除く）は省メモリ読み込みでも効く。
  非表示の行・列を判定できなかったシートは `convert.hidden_unknown`（warning）で知らせる。
- Office 形式（zip）は展開する前に、展開後の合計サイズ（既定 1024MB、`--max-unzipped-mb`）と、1MB 以上のファイルの
  圧縮率（既定 500 倍、`--max-zip-ratio`）を調べ、超えたら変換せずに終了コード 2 で止める（zip 爆弾対策）。

**Word**: 変更履歴は既定で「承認後」の内容（`--track-changes`）。表の縦結合は値を繰り返し、入れ子の表は
セル内に `列 / 列` を行ごとに `<br>` で並べる。
番号付きの箇条書きは Word の番号どおりの **続き番号**（段落や表を挟んでも `3.` から続ける）。番号付けの単位は
Word と同じ（同じ抽象番号を使う一覧は番号を続け、`startOverride` で振り直す指定があればそこから。開始番号 `w:start`
も反映。スタイル `List Number` 等で番号を付けた段落はスタイルごとに続ける）。ある段の番号が進むとより深い段は 1 から。

**PDF**: 見出し・箇条書き・段落の区切りは文字サイズ・太字・行頭記号・行間からの **推定**。
2 段組みは左段 → 右段の順。ページの上端・下端（高さの 8%）に繰り返し出る行（ヘッダー・フッター・ページ番号）は除去する
（`--keep-running-headers` で除去しない）。除く条件は次の 2 つで、どちらでもない行は残す（本文を誤って消さない）。
  - 文字がまったく同じ行（空白は無視）: **半数以上**（2 ページ以上）のページに出たもの（例: `運用手順書 第3版`）
  - 数字だけが違う行: **全ページ** に出て、違う数字がページ番号と同じ歩みで 1 ずつ増えるもの（例: `1 / 2`・`- 3 -`・`Page 3 of 10`）。
    `合計 1200 円` と `合計 980 円` のように数字の違い方がページと合わない行、表紙など一部のページに無い行は残す

  除いた文字数は、ロス検知（`loss.raw_text`）の元の文字数から **引かない**（誤って本文を消したときも検知できるように）。
  そのため、ページが少なくヘッダー・フッターの割合が大きい PDF では `loss.raw_text` が出ることがある。除いた種類と文字数は
  `convert.note` に出す。
OCR したページは改行を保ったまま出力する（推測で結合しない）。

### Front Matter（`--front-matter`）

```yaml
---
title: "<元ファイル名（拡張子なし）>"
id: "<人が付ける識別子。空なら未付与。再変換で前回の値を引き継ぐ（source が同じときだけ）>"
source: "<元ファイル名>"
source_sha256: "<元ファイルの SHA-256（16 進 64 桁）>"
generator: "doc2md <版>"
---
```

値はすべて JSON 文字列（YAML としても読める）。日時は入れない（同じ入力から常に同じ出力にするため）。
Front Matter は変換ロス検知の集計に含めない。
前回の出力から `id` と `source` を読むときは、人が BOM 付き（Windows のメモ帳など）・改行 CRLF で保存し直したファイルも読む。

### llms.txt / llms-full.txt（`--llms-txt`）

- `llms.txt`: `# 変換済みドキュメント`、件数の引用、`## 文書` の下に `- [<最初の見出し>](<相対パス>): 元ファイル <名前>` を
  出力ファイル名順に並べる。見出しの `[` `]` と、元ファイル名の Markdown の記号は `\` でエスケープし、相対パスの空白・括弧は
  パーセントエンコードする（`a]b(c` のような名前でもリンクが壊れない）
- `llms-full.txt`: 各文書を `<!-- source: <元ファイル名> -->`（`--` は `- -` に崩す）+ 本文（Front Matter を除く）にし、`---` 区切りで連結

## 2. 変換レポート

### meta

| キー | 型 | 内容 |
|---|---|---|
| `inputs` | 数値 | 対象ファイル数 |
| `converted` | 数値 | 変換できたファイル数 |
| `out_dir` | 文字列 | 出力先 |

### rule_id 一覧

| rule_id | severity | 意味 | 利用側の対応 |
|---|---|---|---|
| `convert.ok` | info | 変換成功。`message` に出力先、`actual` に統計（`headings= lists= tables= rows= images= chars=`、PDF 経由なら `via-pdf`） | — |
| `convert.note` | info | 形式ごとの注意事項（結合セルを埋めた、2 段組みとして読んだ 等） | 必要に応じて確認 |
| `convert.renamed` | info | 出力名が他の入力と重なったため、別の名前で書き出した（`message` に出力先） | 出力先のファイル名を確認 |
| `convert.overwrite_other_source` | warning | 既存の出力（前回の実行）が別の元ファイルから作られていたが上書きした | 出力先を分けるか、古い出力を整理 |
| `convert.warning` | warning | 利用者が確認すべき事項（未確定の変更履歴、非表示行を含む、数式の計算結果が無い、OCR したページがある、OCR できない 等） | **内容を確認**。AI エージェントは利用者に伝える |
| `loss.headings` / `loss.list_items` / `loss.tables` / `loss.table_rows` / `loss.images` | warning | 変換時に認識した要素より出力が少ない（整形の段階で欠落） | 目視確認。不具合の可能性 |
| `loss.text` | warning | 本文の文字数が認識した量の 95%（`--loss-threshold`）未満 | 同上 |
| `loss.number_format` | warning | Excel のセルの表示形式を再現できず、書式なしの値で出力した（`message` に表示形式と `シート名!セル`、6 セル目以降は件数のみ。表示形式ごとに 1 件） | 原本で該当セルの表示を確認し、必要なら Markdown を手で直す |
| `loss.table_as_paragraph` | warning | Excel の表らしい範囲で見出し行が見つからず、段落（`値 / 値`）で出力した（`message` に `シート名!A1:C3`） | `--header-row` で見出し行を指定して再変換 |
| `convert.large_workbook` | warning | 大きなブック（`--max-cells` 超え）を省メモリで読んだ。結合・複数の表・注記の判定をしていない（`--header-row`・`--skip-hidden` は効く） | 必要なら `--max-cells` を上げて再変換 |
| `convert.hidden_unknown` | warning | 省メモリ読み込みのシートで非表示の行・列を判定できず、すべて出力した | `--max-cells` を上げて通常の読み込みで再変換 |
| `loss.raw_text` | warning | **元ファイルから直接数えた** 文字の 95%（`--loss-threshold`）未満しか出力されていない（未対応の要素がある） | 図形・グラフ等を確認。`--via-pdf` と比較 |
| `convert.failed` | error | 変換に失敗（`--continue-on-error` 時のみ。それ以外は終了コード 3） | ファイルが壊れていないか確認 |
| `convert.input_error` | error | そのファイルだけの入力の誤り（zip の展開サイズ・圧縮率の上限超え、LibreOffice が無いのに .doc 等を指定、draw.io の圧縮された図の展開サイズの上限超え）。`--continue-on-error` 時のみ（最後に終了コード 1）。それ以外は終了コード 2 で即終了 | 入力ファイル・外部ツールを確認 |

`location` は元ファイル名です。

### 終了コード

| コード | 条件 |
|---|---|
| 0 | すべて変換できた（warning があっても 0。`--strict` なら 1） |
| 1 | `convert.failed` または `convert.input_error` がある（`--continue-on-error` での一部失敗）、または `--strict` で warning がある |
| 2 | 未対応の形式、入力が無い、オプションの誤り、必要な外部ツール（LibreOffice 等）が無い、zip の展開サイズ・圧縮率が上限超え（`--continue-on-error` なしのとき）。`--continue-on-error` では、ファイル単位の入力の誤り（`convert.input_error`）は他のファイルの変換を続け、レポートと llms.txt を出してから 1 で終わる。引数の誤り・未対応の形式の直接指定は `--continue-on-error` でも即 2 |
| 3 | 想定外のエラー |

### dry-run（`--dry-run`）

ファイルは書かない。findings は `plan.route`（info: 読み取り方式）、`plan.missing_tool`（error: 必要な外部ソフトが無い）、
`plan.unsupported`（warning）。error があれば終了コード 1。
