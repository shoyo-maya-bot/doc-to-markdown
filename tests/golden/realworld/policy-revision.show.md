# 経費精算規程

## 第1条 目的

本規程は、業務上の経費の精算手続きを定める[^1]。詳細は[規程集](https://example.com/rules/expense)を参照する。

## 第2条 対象と上限

宿泊費の上限は ~~8000 円~~<ins>10000 円</ins>とする。

交通費は実費[^c1]を支給する。

区分ごとの扱いは次の表のとおり。

> **テキストボックス**: 注意: 領収書の原本を提出すること

| 区分 | 手段 | 扱い |
| --- | --- | --- |
| 交通費 | 電車 | 実費 |
| 交通費 | タクシー | 事前承認 |
| 宿泊費 | 10000 円まで |  |
| 接待費 | 社内 / 不可<br>社外 / 可 | 部長承認 |

### 申請の手順

1. 申請書を作成する
2. 上長が承認する
- 添付するもの
  - 領収書
  - 行程表
